# G-NET97 Advanced C# — Assignment 1: Generics

C# console application demonstrating Advanced C# generics concepts, organized with a separate folder per topic.

## Topics Covered

- **GenericClass** — Generic classes
- **GenericMethods** — Generic methods
- **GenericInterface** — Generic interfaces
- **GenericInheritance** — Generics with inheritance
- **Constraints** — Type constraints (`where` clauses)
- **CovarianceAndContravariance** — Variance in generic interfaces/delegates
- **MultipleTypeParameters** — Multiple type parameters
- **StaticMembers** — Static members in generic classes
- **DefaultKeyword** — `default` literal and `default(T)`
- **Cache** — Generic caching example

## How to Run

```bash
dotnet run
```

- C# / .NET
